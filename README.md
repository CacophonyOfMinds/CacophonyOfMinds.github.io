# CacophonyOfMinds.github.io

Welcome to my overarching puzzle for the Gang's Awful Resource Pack, called "Cacophony of Minds." This puzzle pack contains twelve puzzles based on a myriad of skills tailored to the participants in the resource pack, from graduate-level mathematics to Geometry Dash. Because this puzzle pack is made specifically for these people, it is expected that all of the resources in this pack will already be owned. To keep the element of surprise, all of the necessary resources will be kept secret until they are required. Of course, each puzzle will necessitate that the participant owns Minecraft: Java Edition (v1.21) and the Gang's Awful Resource Pack. The Gang's Awful Resource Pack can be found here: (link)

There are a total of six people participating in this puzzle pack, and there are two puzzles centered around each person. One puzzle pertaining to their work, and one puzzle pertaining to their hobby. Each of these puzzles have three sections to them: an access point from Minecraft to this website, a website portion that unlocks the start of the next puzzle in Minecraft, and a smaller extra task that reveals a recipe for a music disc pertaining to the puzzle. 

A major goal of the Gang's Awful Resource Pack is to find all of the music discs that are in the pack. There are custom music discs with custom songs linked to them that are hidden throughout the pack, and can be tracked using the new achievement tab in the advancement menu. The reward for completing the Cacophony of Minds is not a music disc, but there are music discs that can be unlocked along the way.

# How do I Play / Start Cacophony of Minds?

Go to CacophonyOfMinds.github.io. This is the password entry site - while the password for the first puzzle is hidden on the site itself, the rest of the passwords will come from puzzles made from the discs in the Pack. Enter each of the passwords in the textbox in the center of the site - or alternatively, edit the URL by appending the password to the end.

# Disclaimer

Because I chose to make this puzzle on Github, it should be noted that all of the puzzle website resources are blatantly available (and regulating the puzzle order is impossible if the puzzles are available all the time.) Therefore, this puzzle pack works only on an honor code system. If you choose to play Cacophony of Minds, it is expected that you will not look at future puzzles' resources in both this repository and other repositories on this account named for other puzzles. Doing so defeats the purpose of the puzzle. I do not support spoiling any of the future parts of the puzzle either.
